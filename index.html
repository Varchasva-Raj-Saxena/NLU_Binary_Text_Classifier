Abstract

This project details the design and implementation of a machine learning classifier capable of distinguishing between "Sports" and "Politics" news articles with approximately 96% accuracy. We constructed a balanced dataset of 25,000 documents from the AG News corpus and conducted a comparative analysis of three feature representation techniques (Bag of Words, TF-IDF, N-Grams) across three supervised learning algorithms.

1. Data Acquisition & Curation

Why AG News over Web Scraping?

Initially, we attempted to scrape data from Wikipedia and RSS feeds. However, this approach failed due to two primary issues:

  • Anti-Bot Protections: High-volume requests were blocked by major news sites.
  • Unstructured HTML: Cleaning ads, navigation bars, and HTML artifacts introduced significant noise.

Consequently, we utilized the AG News corpus, a standard benchmark dataset, to ensure high-quality ground truth labels.

Dataset Construction Code

The code below demonstrates loading the massive dataset and filtering specifically for our binary classification task (Politics vs. Sports).

import pandas as pd
from datasets import load_dataset

# 1. Load AG News (Labels: 0=World, 1=Sports, 2=Business, 3=Sci/Tech)
dataset = load_dataset("ag_news")
full_df = pd.DataFrame(dataset['train'])

# 2. Filter for World (Politics) and Sports
# We remap Class 0 (World) to "Politics" and keep Class 1 as "Sports"
filtered_df = full_df[full_df['label'].isin([0, 1])].copy()

# 3. Balance the Dataset
# We sample exactly 12,500 documents per class to prevent majority class bias
df_politics = filtered_df[filtered_df['label'] == 0].sample(12500, random_state=42)
df_sports = filtered_df[filtered_df['label'] == 1].sample(12500, random_state=42)

final_df = pd.concat([df_politics, df_sports])

2. Methodology: Feature Representation

Machine learning models require numerical input. We compared three vectorization strategies:

  • Bag of Words (BoW): Represents text as a vector of word counts. While simple, it often biases models toward frequent but uninformative words.
  • TF-IDF: Weighs terms based on importance. It penalizes words that appear in too many documents (like "the") and highlights distinctive terms (like "election" or "touchdown").
  • N-Grams (Bi-grams): Captures local context by including adjacent word pairs (e.g., "White House" vs "White" and "House"). This helps distinguish phrases that change meaning when words are combined. 
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer

features = {
    # Simple word counts
    "Bag of Words": CountVectorizer(stop_words='english', max_features=10000),
    
    # Weighted importance
    "TF-IDF": TfidfVectorizer(stop_words='english', max_features=10000),
    
    # Contextual pairs (Unigrams + Bigrams)
    "N-Grams (1,2)": TfidfVectorizer(ngram_range=(1, 2), stop_words='english', max_features=10000)
}

Why did SVM + TF-IDF perform best?

The Linear SVM combined with TF-IDF achieved the peak accuracy of 95.80%. This success is attributed to:

  • Signal Isolation: TF-IDF effectively down-weighted generic words, allowing strong topic-specific terms (e.g., "treaty", "goal") to drive the vectors.
  • Margin Maximization: SVMs are robust to overfitting in high-dimensional spaces. For documents with ambiguous terms (e.g., "race" or "win"), the SVM aggregates the weights of all other unique tokens more effectively than Naive Bayes.

5. Limitations

Despite achieving high accuracy, the system has specific constraints:

  • Static Dataset: The model is trained on historical data. It may struggle with new political figures or emerging sports stars (Out-of-Vocabulary problem).
  • Short Text Ambiguity: Headlines under 5 words often lack enough features for TF-IDF to generate a distinct vector.
  • Domain Overlap: "Sports Politics" articles (e.g., legislation on stadium funding) contain features from both classes, confusing the linear boundary.

Conclusion

This project successfully developed a text classifier with over 95% accuracy. The results indicate that while simple Bag of Words models are effective, the combination of TF-IDF features and a Linear Support Vector Machine provides the most robust solution for distinguishing Sports from Politics. Future work could involve Deep Learning (BERT) to handle semantic nuances better.
